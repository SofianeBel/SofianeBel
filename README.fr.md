# Salut, moi c'est Sofiane

**🇫🇷 Français** | **🇬🇧 [English](./README.md)**

Développeur full-stack et game dev basé en France.

Je construis des outils développeur, des apps desktop, des serveurs MCP et des projets liés au jeu vidéo.

## Ce sur quoi je travaille

- Tooling IA pour agents de code et workflows locaux
- Serveurs MCP pour outils locaux et workflows game dev
- Apps desktop avec Tauri, C# et intégrations Windows
- Tooling game dev autour de S&box / Source 2

## Projets

- **[GuideME / MyRamadan](https://github.com/SofianeBel/myramadan)**
  App desktop Tauri pour les horaires de prière, le suivi du jeûne, les rappels et l'accompagnement Ramadan.

- **[Serveurs MCP S&box](https://github.com/SofianeBel/sbox-api-mcp)**
  Serveurs MCP pour rechercher dans les APIs et la documentation S&box depuis des outils de code IA.
  [Serveur API](https://github.com/SofianeBel/sbox-api-mcp) · [Serveur Docs](https://github.com/SofianeBel/sbox-docs-mcp)

- **Winshots**
  App Windows locale de capture avec un serveur MCP Codex pour fournir du contexte depuis des screenshots.

- **Sifly Autopilot Engine**
  Moteur local d'automatisation Codex pour transformer une idée brute en V1 vérifiée.

- **WiFi Optimizer**
  Prototype Android-first pour cartographier la qualité Wi-Fi d'un logement et trouver un meilleur placement de répéteur.
